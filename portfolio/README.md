# Vidyashree Nandani Portfolio

A personal portfolio website built with React and Vite.

## Technologies used

- React
- Vite
- JavaScript
- JSX
- CSS
- Lucide React

## How to install

```bash
npm install
```

## How to run locally

```bash
npm run dev
```

## Where to add profile photo

Place the profile photo in:

```text
src/assets/profile/profile.jpg
```

## Where to add project images

Place project images in:

```text
src/assets/projects/
```

## Where to add certificate images

Place certificate images in:

```text
src/assets/certificates/
```

## Where to add achievement image

Place the achievement image in:

```text
src/assets/achievements/prompt-engineering.jpg
```

## Where to add GitHub link

Update this value in:

```js
src/data/portfolioData.js
```

```js
github: 'ADD_GITHUB_LINK_HERE'
```

## Where to add resume link

Update this value in:

```js
src/data/portfolioData.js
```

```js
resume: 'ADD_RESUME_LINK_HERE'
```

## Where to add project links

Update the project URLs in:

```js
src/data/portfolioData.js
```

Example:

```js
projectLink: 'ADD_PROJECT_LINK_HERE'
```

## How to build the project

```bash
npm run build
```
